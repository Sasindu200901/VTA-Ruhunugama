VTA Ruhunugama Full HTML Frontend
================================
Open index.html in a browser.

This is a frontend-only demonstration using browser localStorage.
Demo Student: MIS001 / student123
Demo Teacher: T001 / teacher123
Demo Admin: admin / admin123

The VTA logo is in assets/vta-logo.png.

Teacher can update existing student details and attendance.
Admin can add students, teachers and notices.

For real deployment, connect these pages to a server/database and implement secure authentication.
